# 划词搜索 (G/B)

选中网页文字后：

- **G**：用 Google 搜索选中的文字
- **B**：用百度搜索选中的文字

## 安装 / 更新

1. 打开 `chrome://extensions`
2. 打开右上角的「开发者模式」
3. 点击「加载已解压的扩展程序」，选择本文件夹

**修改代码或更新版本后**：在 `chrome://extensions` 里点扩展卡片上的刷新按钮，然后**刷新网页**（内容脚本只在页面加载时注入，旧标签页不会自动生效）。

## 说明与限制

- 单键快捷键由页面内的按键监听实现（Chrome 的 commands API 只支持 Ctrl / Alt / Cmd 组合键）。
- 只在「焦点不在输入框或可编辑区域」且「有选中文字」时响应，避免抢走网页本身的单键快捷键和正常打字。
- 本扩展不再注册右键菜单。
- `chrome://` 页面、Chrome 应用商店等页面不允许扩展注入脚本，快捷键在那里无效。
- 如果网页自己也用这些键做快捷键，G / B 会在有选中文字时被本扩展优先处理。

## 快捷键没反应时

1. 在 `chrome://extensions` 点扩展卡片上的刷新按钮，然后刷新当前网页。
2. 打开扩展的「详情」，确认「网站访问权限」是「在所有网站上」。
3. 确认页面焦点不在输入框 / 可编辑区域里（那里的按键不会被拦截）。
4. 确认已经选中了文字。
5. 确认不是 `chrome://` 页面、Chrome 应用商店或 PDF 内置查看器。
