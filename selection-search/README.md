# 划词搜索 (H)

选中网页文字后：

- **H**：呼出「划词搜索」面板（没选中文字也会弹出提示），面板里再按 **G**（Google）或 **B**（百度），也可以直接点面板上的按钮
- **G**：选中文字后直接用 Google 搜索
- **B**：选中文字后直接用百度搜索
- **Esc** 或点击面板外的区域：关闭面板
- 右键选中文字：菜单里选择 **Google 搜索 (G)** / **百度搜索 (B)**

## 安装 / 更新

1. 打开 `chrome://extensions`
2. 打开右上角的「开发者模式」
3. 点击「加载已解压的扩展程序」，选择本文件夹

**修改代码或更新版本后**：在 `chrome://extensions` 里点扩展卡片上的刷新按钮，然后**刷新网页**（内容脚本只在页面加载时注入，旧标签页不会自动生效）。

## 说明与限制

- 右键菜单里的「划词搜索 (H)」是扩展分组标题，子项是 **Google 搜索 (G)** / **百度搜索 (B)**。
  Chrome 原生右键菜单不支持扩展注册真正的加速键，这些 (H) / (G) / (B) 只是文字提示；
  真正的单键快捷键由页面内的按键监听实现（Chrome 的 commands API 只支持 Ctrl / Alt / Cmd 组合键）。
- 只在「焦点不在输入框或可编辑区域」时响应；其中 G / B 还需要有选中文字，H 随时可用。
- 划词搜索面板用 Shadow DOM 渲染，网页样式不会影响它，它也不会影响网页布局。
- `chrome://` 页面、Chrome 应用商店等页面不允许扩展注入脚本，快捷键在那里无效。
- 如果网页自己也用这些键做快捷键，G / B 会在有选中文字时被本扩展优先处理，H 会被本扩展优先处理。

## 快捷键没反应时

1. 在 `chrome://extensions` 点扩展卡片上的刷新按钮，然后刷新当前网页。
2. 打开扩展的「详情」，确认「网站访问权限」是「在所有网站上」。
3. 确认页面焦点不在输入框 / 可编辑区域里（那里的按键不会被拦截）。
4. 确认不是 `chrome://` 页面、Chrome 应用商店或 PDF 内置查看器。
